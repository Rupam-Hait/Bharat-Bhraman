From the iconic Taj Mahal to the serene backwaters of Kerala, this website provides interactive maps, detailed destination information, and community travel groups.

### 🎯 Mission

To make India's rich cultural heritage and natural beauty accessible to travelers worldwide through an engaging, user-friendly platform.

## 🚀 Getting Started

### ✅ Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for Google Maps API and external resources)

### ⚙️ Installation

**1. Clone the repository**
```bash
git clone https://github.com/Rupam-Hait/Bharat-Bhraman.git
cd Bharat-Bhraman
```

**2. Open the website**
```bash
# Simply open final.html in your browser
open final.html

# Or use a local server
python -m http.server 8000
# Then visit http://localhost:8000/final.html
```

**3. Google Maps Setup**
- The website uses the Google Maps API
- Ensure your API key is valid and has Maps JavaScript API enabled
- ⚠️ Replace the demo API key with your own before deploying to production
